Looker file icons: one red icon per kind of file

Every icon is solid Looker red, shaped by what the file is: the document page only for documents (PDF), a film frame for video, a camera for RAW, a cube for 3D models, and so on. Under 32 px each one drops to a simpler form so it stays crisp. A second set adds a small extension tag at 48 px and up, for telling JPG from PNG at a glance.

The set

With an extension tag (48 px and up)

The same icons with a small dark tag naming the extension. The document page already carries its extension, so it has no tag.

Every size

16, 20, 24, 32, 48, 64 and 256 px, as Windows asks for them; the 32 px and smaller ones enlarged pixel for pixel underneath.

In Explorer

Details view at 16 px (100 %) and 24 px (150 % scaling), and a large-icon grid at 96 px. Photos and videos usually show their thumbnails in large-icon views; these are what show before the thumbnail is ready, or when thumbnails are off.
