Looker file icons: one per extension

Four layouts, each drawn from the real Looker mark, for the icon Windows shows beside a file when Looker is its default app. Every size Windows asks for is shown, the small ones enlarged pixel for pixel underneath. Under 32 px there's no room for readable letters, so each layout has a small-size form.

In Explorer

Details view uses the 16 px icon (24 at 150 % scaling); large-icon views use 48 to 256 px, though photos and videos usually show their thumbnails there instead.

Colour by kind optional

The same layouts with the band coloured by what the file is: photos Looker red, camera RAW amber, video violet, documents slate, 3D teal. It reads faster at a glance, but drifts from a single brand colour.
