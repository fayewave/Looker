## Viewer

- Opens in a blink, with the next files in the folder already loaded.
- Photos, camera RAW, video, audio, PDFs, archives, 3D models and code: 288 file types.
- Zoom up to 25600 %, fullscreen, slideshow and a thumbnail strip.
- Info panel with EXIF and a histogram; edit titles, keywords and ratings.
- Crop, straighten, and adjust light and colour (`E`).
- Colour managed; HDR photos and video at full brightness on an HDR display.
- Black, Paper and Light themes. Works with screen readers.

<img src="brand/screenshots/readme-info.jpg" alt="The info panel and the thumbnail strip" width="700">

## File explorer

- Beside the photo, with tabs, bookmarks, colour tags and thumbnails.
- Move, copy, rename and delete with undo; drag to and from other apps.
- Filter a folder by field: `camera:x100`, `rating:4+`, `taken:2024`.

<img src="brand/screenshots/readme-explorer.jpg" alt="The file explorer beside a photo" width="700">

## Video and audio

- 4K and HDR video, frame stepping, chapters, and subtitles of every kind.
- Audio with its cover, a waveform or spectrogram, and loops.
- iPhone Live Photos and Android motion photos play.

<img src="brand/screenshots/readme-video.jpg" alt="A 4K video playing" width="700">

## Text and code

- A tabbed editor with find and replace, spell check and Markdown.
- Code coloured in 20+ languages; JSON, XML, YAML, TOML and CSV checked as you type.

## Looker Pro

## Keys

| Key | Action |
|---|---|
| `←` `→` | Previous / next |
| Wheel, `Ctrl+0`, `Ctrl+1` | Zoom, fit, 100 % |
| `F11`, `F5`, `Space` | Fullscreen, slideshow, play / pause |
| `Ctrl+E`, `Ctrl+I`, `Ctrl+Shift+T` | File explorer, info panel, thumbnails |
| `E`, `Ctrl+R` | Edit, rotate |
| `Delete`, `F2` | Delete, rename |
| `Ctrl+,` | Settings |
